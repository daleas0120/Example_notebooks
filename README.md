# Example_notebooks
A collection of simple tutorials

- *Network Pruning Example*: Simple implementation of pruning weights from a fully-connected neural network to improve the efficiency
- *Persistence Diagram Playground*: Practice analyzing data using persistence homology 
- *LSTM AE Anomaly Prediction*: Train an LSTM autoencoder on power grid data to detect power grid faults
- *Loss Landscapes*:Example of how to calculate a loss landscape
